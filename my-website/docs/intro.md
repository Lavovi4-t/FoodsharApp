# Добро пожаловать в FoodsharingApp

FoodsharingApp - это фудшеринг приложение для передачи еды с истекающим сроком годности.

## Основные возможности

- Поиск еды на карте
- Публикация объявлений
- Бронирование еды
- Чаты с пользователями
